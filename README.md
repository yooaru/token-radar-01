A token launch radar: it reads a sealed snapshot of the DefiLlama protocol universe, ranks every
protocol whose own token does not exist yet by what that token would be worth on the snapshot's own
figures, and writes a dashboard with a filterable board, a detail view per protocol and the steps
to farm each one.

## Run it

```sh
node main.ts --input /input/snapshot.json
```
