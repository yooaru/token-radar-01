How the value model works

Every implied value on this board is arithmetic on the snapshot's own figures. No protocol is named in the model, so the same function scores every row, and the page recomputes each row from the factors below and shows them side by side.

  1. size (TVL in millions) 0.55 × 2,000,000 TVL with diminishing returns: ten times the TVL is worth far less than ten times the value.
  2. growth 1 + (7-day TVL change, clamped to −60%..+120%) / 100 × 0.5 Protocols whose TVL is shrinking are marked down; the clamp keeps one bad week from deciding a rank.
  3. maturity 0.75 + min(days tracked with no token, 730) / 730 × 0.5 The longer a protocol has run without a token, the closer it is to issuing one.
  4. breadth min(1 + 0.06 × (chains − 1), 1.30) A protocol on many chains reaches more users, and points programmes usually follow them.
  5. category the prior for the snapshot's own category field One number per category, from what that kind of protocol has been worth when it issued.
  6. implied size × growth × maturity × breadth × category The entry's own claim about what the token would be worth, not a market quote and not a prediction of a launch.

—

The board is built from one sealed snapshot of the DefiLlama public protocol list. Implied value is this entry's own arithmetic on that snapshot, not a quote and not a promise that a token is coming. A protocol that records no token may still never issue one.
